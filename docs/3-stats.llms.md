## Common Checks

    description: Get suite-level metadata.
    command: curl -fsSL https://www.x-cmd.com/rpm/repodata/repomd.xml

  fetch_primary:
    description: Get package metadata (gzipped).
    command: curl -fsSL https://www.x-cmd.com/rpm/repodata/primary.xml.gz | gunzip

  fetch_rpm:
    description: Download the RPM.
    command: curl -fsSLO https://www.x-cmd.com/rpm/Packages/x-cmd_0.9.9_all.rpm

  verify_digest:
    description: Verify the package against an expected SHA-256 hash.
    command: |
      EXPECTED="<sha256-from-primary.xml>"
      echo "$EXPECTED  x-cmd_0.9.9_all.rpm" | sha256sum -c -

  rpm_verify:
    description: |
      One-shot verification: digest + (post-signing) signature.
      Today: digest only. After signing: also shows key ID.
    command: rpm -Kv https://www.x-cmd.com/rpm/Packages/x-cmd_0.9.9_all.rpm

## Sibling Comparison

vs_deb:

  layout:
    deb: pool/ + dists/stable/{Release,main/binary-{amd64,arm64,armhf,i386,all}/Packages{,.gz}}
    rpm: flat Packages/ + repodata/
  components_or_suites:
    deb: multi-Component Suite (latest/lts/safe/unsafe, planned)
    rpm: single flat repo (no components today)
  per_arch_indices:
    deb: yes (5 indices, byte-identical because x-cmd is `Architecture: all`)
    rpm: no (`noarch` covers all — only one RPM needed)
  metadata_generator:
    deb: dpkg-scanpackages + apt-ftparchive (run inside Debian container)
    rpm: createrepo_c (run inside Fedora container)
  signing:
    deb: '[trusted=yes]' today
    rpm: 'gpgcheck=0 + repo_gpgcheck=0' today
  client:
    deb: apt
    rpm: dnf / yum / zypper

## Summary

Snapshot of what `x-cmd/rpm` publishes today: one `noarch`
RPM (x-cmd 0.9.9, ~4.16 MB), metadata generated by
`createrepo_c` (gzip-compressed for RHEL 7 `yum` compat),
flat `Packages/` + `repodata/` layout — distinct from the
sibling Debian repo's `pool/` + `dists/` layout. Single suite,
no per-arch split, single suite-level manifest. Event-driven
publishing on upstream release + daily CDN sync from this
GitHub repo; no fixed CI rebuild schedule.
